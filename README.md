# Python OOPs

A collection of Python programs and mini-projects focused on learning and practicing **Object-Oriented Programming (OOP)** concepts.

This repository contains examples, assignments, and practical implementations that helped me understand how OOP concepts are used to structure Python programs.

## 📚 Topics Covered

- Classes and Objects
- Constructors
- Instance Attributes
- Class Attributes
- Encapsulation
- Inheritance
- Multiple Inheritance
- Function Overriding
- Abstraction
- Constructor Overloading using Default Arguments
- `super()`
- `__str__()` and other special methods
